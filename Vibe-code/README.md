# Kas Kelas Digital

Aplikasi Manajemen Kas Kelas berbasis Node.js, Express, PostgreSQL, dan Discord Bot.

## Fitur
- **Dashboard Web Responsive:** Siswa bisa mengecek matriks kas harian, melakukan deposit, dan membayar kas secara manual.
- **Discord Bot Control Center:** Memudahkan bendahara/admin mengelola akun siswa, pengeluaran kelas, dan mencetak laporan Excel (.xlsx).
- **PostgreSQL Database:** Penyimpanan terstruktur untuk saldo deposit dan pembayaran.
